# Mic Toggle

**Горячая клавиша для включения и выключения микрофона в Windows.**
Иконка в трее показывает, включён ли микрофон. И больше ничего.

## Зачем

У многих микрофонов нет физической кнопки отключения: у веб-камер, колонок со встроенным микрофоном, недорогих USB-микрофонов. В Windows нет глобальной горячей клавиши для микрофона, а лезть каждый раз в параметры звука неудобно. Готовые решения либо входят в большие пакеты вроде PowerToys, либо работают только внутри одной программы (Discord, Zoom).

Mic Toggle решает одну эту задачу:

- одно сочетание клавиш выключает и включает микрофон сразу во всех программах;
- иконка в трее показывает текущее состояние;
- один exe-файл размером около 1 МБ: без установки, служб и фоновых процессов, кроме самой программы.

## Установка

1. Скачайте `MicToggle.exe` со страницы [последнего релиза](https://github.com/kuscoder/mic-toggler/releases/latest). Для 32-битной Windows берите `MicToggle-x86.exe`.
2. Запустите его. В трее появится иконка микрофона.

Если иконку не видно, она спрятана под стрелкой «Отображать скрытые значки». Перетащите её на панель задач, чтобы она всегда была на виду.

> [!NOTE]
> Windows SmartScreen или антивирус могут предупредить о неизвестной программе. Так бывает с любым неподписанным exe, собранным из AutoHotkey. Исходный код открыт, и программу можно [собрать самому](#сборка-из-исходников).

## Использование

| Действие                                        | Результат                     |
| ----------------------------------------------- | ----------------------------- |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>M</kbd> | Выключить / включить микрофон |
| Левый клик по иконке в трее                     | То же самое                   |
| Правый клик по иконке в трее                    | Меню настроек                 |

|                                      Иконка                                       | Состояние                       |
| :-------------------------------------------------------------------------------: | ------------------------------- |
|             <img src="assets/mic_on.png" width="20" alt="Микрофон">              | Микрофон включён                |
| <img src="assets/mic_off.png" width="20" alt="Перечёркнутый микрофон">            | Микрофон выключен или не найден |

При каждом переключении звучит короткий сигнал: высокий означает «включён», низкий означает «выключен».

## Настройки

Все настройки находятся в меню по правому клику на иконке и сохраняются автоматически.

- **Микрофон.** Какое устройство выключать. По умолчанию это системный микрофон Windows, а также микрофон по умолчанию для связи, если в Windows назначен другой. Список обновляется при каждом открытии меню.
- **Сочетание клавиш.** Любое сочетание с <kbd>Ctrl</kbd>, <kbd>Alt</kbd>, <kbd>Shift</kbd> или <kbd>Win</kbd>, либо одна из клавиш <kbd>F1</kbd>–<kbd>F24</kbd>. Работает в любой раскладке.
- **Звуковые сигналы.** Включить или выключить сигнал при переключении.
- **Запускать вместе с Windows.** Добавляет ярлык в папку автозагрузки.
- **Язык.** Английский или русский. При первом запуске выбирается по языку системы.

Настройки хранятся в `%AppData%\MicToggle\settings.ini`.

## Как это работает

Mic Toggle ставит отметку **«Выключить звук»** на самом устройстве записи. Это тот же флажок, что в _Панель управления → Звук → Запись → Свойства микрофона → Уровни_. Отметка ставится через стандартный интерфейс Windows Core Audio (`IAudioEndpointVolume::SetMute`).

Что из этого следует:

- **Звук выключается во всех программах сразу.** Discord, Zoom, Telegram и браузер получают тишину, их настройки трогать не нужно.
- **Устройство остаётся подключённым.** Программы не теряют микрофон и не переключаются на другой, как бывает при отключении устройства в параметрах Windows. После включения звук сразу идёт дальше.
- **Состояние всегда актуально.** Если микрофон выключили в другом месте (например, в параметрах Windows), иконка в трее обновится в течение секунды.
- **Ничего не записывается и не передаётся.** Программа не открывает поток с микрофона и не обращается к сети.

## Ограничения

- **Один микрофон за раз.** Mic Toggle выключает только выбранный микрофон. Если у вас их несколько, проверьте, что в меню выбран нужный: остальные останутся включёнными. Мы думаем над тем, как это расширить, и будем рады [вашему вкладу](CONTRIBUTING.md).
- **ASIO и эксклюзивный режим.** Программы, которые работают со звуковой картой напрямую через драйверы ASIO или эксклюзивный режим WASAPI (в основном программы для записи музыки и другой профессиональный софт), обходят системный микшер Windows, поэтому выключение на них не действует.

## Сборка из исходников

Понадобится [AutoHotkey v2](https://www.autohotkey.com/). Компилятор Ahk2Exe можно установить вместе с ним.

1. Склонируйте репозиторий:
   ```
   git clone https://github.com/kuscoder/mic-toggler.git
   ```
2. Откройте **AutoHotkey Dash → Compile** и выберите `MicToggle.ahk`.
3. Нажмите **Convert**. Рядом со скриптом появится `MicToggle.exe` со вшитыми иконками.

Из командной строки:

```
"C:\Program Files\AutoHotkey\Compiler\Ahk2Exe.exe" /in MicToggle.ahk /base "C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe"
```

Если AutoHotkey v2 установлен, `MicToggle.ahk` можно просто запустить двойным кликом, без компиляции.

## Удаление

1. Снимите галочку **«Запускать вместе с Windows»**, если она стоит.
2. Выберите **«Выход»** в меню.
3. Удалите `MicToggle.exe` и папку `%AppData%\MicToggle`.
