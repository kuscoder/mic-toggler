# Changelog

All notable changes to this project are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-26

### Added
- Mute and unmute the microphone with a hotkey (<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>M</kbd> by default) or by clicking the tray icon.
- Tray icon showing the microphone state.
- Tray menu: microphone selection, custom hotkey, sound feedback, start with Windows.
- English and Russian interface.
- 64-bit and 32-bit builds.
- Settings saved to `%AppData%\MicToggle\settings.ini`.
